## 🔍 Log Entry Format

Log entries adhere to standard ISO timestamp format:
```
YYYY-MM-DD HH:MM:SS,ms [LEVEL] Message text
```

### Log Levels
- `INFO`: Normal operational events (database initialization, route rendering, successful API response)
- `WARNING`: Fallback events (e.g. primary AI model rate limit -> automatic fallback model transition)
- `ERROR`: Exception traces (file extraction failures, API network timeouts)
